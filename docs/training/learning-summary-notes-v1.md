# 学習まとめノート v1（Issue #88）

## 完了条件と範囲

- 教材を最後まで進めた後、「学習のまとめを書く」から縦に並んだ4つの定型質問へ回答できる。
- 「次の質問へ」「前の質問へ」と上部の質問ボタンは、同じページ内をスクロールする。前の質問と回答を残し、上に戻って読み返せる。
- 移動位置は質問カード上端を基準にし、ヘッダー下端から16px以上の余白を確保する。質問番号と見出しがヘッダーに隠れないことを前進・後戻り・途中再開で検証する。
- 影響、原因、修正、再発防止について各600文字以内で記入し、質問の移動と途中再開ができる。
- 入力と質問位置をこのブラウザへ保存し、再読み込み後も教材一覧の「まとめノート」から下書きを再開できる。
- 下書きの再開時は、最後に回答・移動した質問へスクロールする。カードの保存ボタンは4問の末尾に配置する。
- 4問に回答したらカードに保存でき、教材名、分類、更新日、影響の抜粋を一覧で振り返れる。カードを開くと全回答を読める。
- カードから教材を読み返し、回答を編集できる。編集中も保存済みカードを保持する。
- 保存に失敗したときは成功を表示せず、回答を画面内に保持して再試行できる。

サーバー同期、認証連携、担当者への提出、採点、Lab実行の変更は対象外。
ノート保存はAssignmentのSubmissionやCompletionとは独立しており、受講完了判定を変更しない。

## 質問

1. **影響**：どんなことが起きる脆弱性でしたか？
2. **原因**：なぜ、その脆弱性が起きたのでしょうか？
3. **修正**：どのように修正すると防げますか？
4. **再発防止**：自分の開発で、何を確認・工夫しますか？

回答例を提示せず、1〜2文で自分の言葉をまとめるための補助文を添える。
学習中のメモや教材の進捗はこの保存対象に含めない。

## 保存仕様

利用者の選択により初版はlocalStorageを使用する。
現在利用できるFile Browser教材を対象とし、教材の論理IDと版で記録を分離する。
キーは`reprokit:learning-note:v1:<lessonId>:<lessonVersion>`。
下書き、表示中の質問、保存済み回答のスナップショット、カード更新日時を保持する。
空白だけの回答は未回答として扱う。
保存データは読み込み時に型、質問位置、文字数、教材参照、日時を検証する。

ノートは同じブラウザ・同じオリジン内に限られ、アカウントごとの分離や端末間同期は提供しない。
ブラウザのデータを消すとノートも消える旨を画面に表示する。
既存のLab Session保存やRunner APIへノートを送らない。

## 検証

- 保存モデルの単体テスト：下書き復元、教材・版の分離、空回答、カードと下書きの分離、不正データ、保存不可。
- Playwright：教材末尾から入力、下書きの再読み込み、カード作成・閲覧・編集、保存失敗と再試行、PCとスマートフォン幅、ダーク表示、横方向のはみ出し。
- リポジトリの`npm run verify`と`git diff --check`。
